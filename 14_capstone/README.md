> **前置知识：** 按路线逐阶段完成

## 交付目标

你不是交一个能点的 Demo，而是交一套证据：

```text
业务建模
+ 可维护前后端
+ 数据一致性
+ 分层测试
+ 安全
+ 缓存/MQ 可靠性
+ 容器化和 CI/CD
+ 可观测和故障恢复
+ Architecture Docs/Rules/MCP/Eval
```
