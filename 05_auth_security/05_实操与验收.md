# 安全实操与验收

> **所属模块：** 05 Security
> **本文用途：** 为项目建立认证 ADR、权限矩阵、安全测试和最小权限。
> **前置知识：** 本模块阅读
> **建议投入：** 15～20 小时

---

## 任务

1. 比较 Session、JWT、外部 OIDC，写 Authentication ADR；
2. 实现 USER/ADMIN/SUPPORT 和细粒度权限；
3. 测 Alice/Bob 对象级越权；
4. 本地演示 SQLi、XSS、CSRF、Mass Assignment、SSRF 风险；
5. `.env.example`、Secret Scan、日志脱敏；
6. 应用/迁移/只读账号分离；
7. 为高风险操作加入审计。
